# 人工智能导论 作业05 实验报告
## 任务一：极简CNN手写数字识别学习摘要

### 一、文章讲解的CNN结构要点
1. 卷积神经网络（CNN）是专门用于处理图像等网格结构数据的深度学习模型，核心优势是**局部连接、权值共享、下采样降维**，能高效提取图像特征。
2. 本次极简CNN包含以下关键组件：
   - 卷积层：使用3×3卷积核对图像进行特征提取，输出16个特征图。
   - ReLU激活函数：增加网络非线性表达能力。
   - 最大池化层：2×2窗口进行下采样，减小特征图尺寸，降低计算量。
   - 全连接层：将高维特征映射到10个类别（0-9数字）。
3. 网络输入为28×28的灰度图像，输出为10分类概率。

### 二、训练流程总结
1. 数据准备：加载MNIST手写数字数据集，进行归一化与张量转换。
2. 模型搭建：定义极简CNN网络结构。
3. 训练设置：使用交叉熵损失函数、Adam优化器。
4. 训练过程：前向传播计算输出 → 计算损失 → 反向传播更新参数。
5. 模型评估：在测试集上计算准确率与损失。
6. 结果可视化：展示数据集样本、预测结果、训练损失曲线。

### 三、个人理解
极简CNN虽然结构简单，但已经完整体现了CNN的核心思想。
在MNIST数据集上，仅5轮训练即可达到**98%以上的测试准确率**，证明了卷积神经网络在图像识别任务上的强大能力。
这个实验非常适合作为深度学习入门，帮助理解卷积、池化、全连接的作用与整体训练流程。
